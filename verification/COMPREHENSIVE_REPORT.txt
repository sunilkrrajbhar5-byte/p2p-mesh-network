MODULE 1 - DATA TRANSFER
PASS: Short text, Hindi, emoji and JSON round-trip through real loopback TCP
using production MeshPacket framing, with exact UTF-8 equality.
PASS: JSON record payload over 1 MiB round-trips through ChunkManager and parses
back identically. A single oversized chat frame is correctly rejected: native
framing uses a 16-bit body length; this is NOT support for a 1 MiB chat message.
PASS: Synthetic recording-like binary data at 512 KiB, 2 MiB and 5 MiB, for both
.m4a and .mp3 filenames. Validates production PRE_ALERT filename, size and digest,
fragment order, reassembly, SHA-256, CRC32 and delivery ACK. These are opaque
bytes, not valid codec fixtures; audio container parsing/playback is untested.
PASS: 10 MiB and 50 MiB video-like bytes with both 64 KiB and 128 KiB socket I/O
buffers. Production file chunks remain 512 KiB with up-to-32 KiB wire fragments.
Tests assert every fragment index, monotonic progress from 0 to total bytes,
exact reconstructed data and verified delivery state. This is not video decoding.
PASS: Injected socket closure after two file fragments fails promptly and cleans
up sockets/jobs; a new connection and full transfer succeeds. No automatic resume
or in-place reconnection is claimed. A stalled read raises SocketTimeoutException;
a subsequent IO-dispatcher task remains responsive.
PASS: A real multi-entry ZIP (Unicode text, binary file and empty file) transfers
with exact SHA-256/CRC32 equality and matching decompressed entries.

MODULE 2 - TOPOLOGY
PASS: Virtual A -> B -> C -> D -> E forwarding uses RelayPacketFilter with
in-memory links. Hop observations are B=1, C=2, D=3, E=4; remaining TTL is 21.
PASS: Duplicate packet suppression, expired TTL and failed next-hop writes.
PASS: Reverse DELIVERY_ACK envelope traverses E -> D -> C -> B -> A. Production
READY/VERIFIED transfer ACKs are additionally exercised by direct TCP transfers
and the existing memory-bridge file-transfer regression.
PASS: After C fails, an explicitly supplied A -> B -> F -> D -> E route delivers.
SKIPPED / NOT IMPLEMENTED: Automatic alternate-route discovery after losing C.
Route-cache learning, expiration and 3-second heartbeat cadence are tested by
existing Step2Checks; this is not autonomous network topology discovery.
SKIPPED / NOT MEASURABLE HERE: 5 km RF coverage. Virtual nodes have no distance;
current frame TTL is 25 and automatic multi-hop integration is incomplete.
Relay storage is bounded RAM forwarding, not a durable disconnected store-and-
forward queue. No such persistence capability is asserted.
